# 产品行为与受众

[English](./product.md)

Vista 是带浏览器界面的通用型智能体。用户描述目标、提供相关路径或附件，与能够调用工具的模型协作。一个可执行文件包含 Go 服务、会话 Worker 和内嵌的 Vue 界面。

## 受众与设计基线

Vista 主要面向能独立使用和配置电脑或手机常用软件的用户：

| 用户类型 | 典型能力 |
| --- | --- |
| 熟练日常使用 | 能管理文件与文件夹、安装软件、调整常用设置，并搜索解决办法。 |
| 进阶工具使用 | 在此基础上，会组合工具、扩展、批处理或简单自动化，能按照说明完成陌生配置。 |

使用 Vista 不以掌握编程、命令行、API 或服务部署为前提。

产品变更遵循以下原则：

- 通过清晰的默认值和指引，让具备日常软件操作能力的用户独立开始使用。
- 逐步展示设置，让用户能按照说明扩展模型、技能和 MCP 工具，不增加日常操作负担。
- 用用途、收益和代价解释陌生控件。
- 围绕任务与协作描述产品，不把部署位置限定为用户自己的电脑。
- 为更熟练的用户保留配置空间。操作能力和学习意愿分别考虑，桌面端和手机端也分别判断。

## 会话行为

- 首次使用先在设置中连接模型服务商。内置连接封装服务商配置；自定义连接明确选择 API 格式及认证。实际可用模型取决于所连接的服务和账号。
- 第一条消息发送时才创建会话及 Worker。打开的会话在准入和健康检查允许时保有常驻 Worker。切换页面或关闭浏览器不停止工作；关闭会话停止其 Worker 和受管工作，保留历史。删除会话移除所属会话数据。
- 同一会话的主线程顺序执行，不同会话、子任务和工具可以并行。执行中的普通发送在决策边界插话；明确排队的消息等待当前执行结束。取消或失败会暂停未投递输入；执行停止后新发消息可开始新工作，无需释放旧队列。
- 重启恢复打开会话的 Worker，将未完成工作记录为中断，不续跑中断的模型请求，也不重放工具副作用。
- 正文、执行过程、提问、检查清单和用量归属于原消息。侧栏分别提示前台执行、仅后台活动、未读回复、待回答、输入队列暂停、Worker 不可用和执行失败。
- 自动选模提供快速和质量模式；手动选择连接、模型及可用推理档位。执行中修改设置从后续执行生效。
- 首次标题由一次独立模型请求生成，不带工具或显式推理强度。标题请求可独立失败；手动命名的标题保留。

运行时的归属关系见[架构](./architecture.zh-CN.md)和[进程生命周期](./process-lifecycle.zh-CN.md)。

## 上下文与资源

已完成的模型轮次和工具结果可供后续消息与 Worker 重启后继续使用。只有上游明确的上下文超限证据才触发自动压缩，并重试失败请求。手动压缩在空闲时共用检查点机制，不自动发送或继续执行。输入区展示保留上下文的估算量，不展示模型容量百分比。见[上下文压缩](./context-compaction.zh-CN.md)。

图片以共享原件文件保存，由会话持有引用。新附件或显式资源读取激活下一次受支持请求的视觉输入，历史图片不自动重复发送。关闭会话保留所有权；删除会话释放关联，完全无引用的文件可手动清理。见[资源](./resources.zh-CN.md)。

编辑和撤回已发送消息仅回退会话及模型历史，文件、shell 副作用和远程改动仍然保留。见[消息回退](./message-revert.zh-CN.md)。

## 个性化与扩展

- 全局提示词位于用户配置根目录的 `AGENTS.md`，在执行开始时读取。目录局部规则通过工具发现、读取；作用范围内更近的规则优先，用户当前明确请求优先于默认规则。
- 记忆保存跨会话的明确长期偏好。用户在个性化中管理；仅主智能体能调用 `memory`，子智能体继承偏好快照。删除单个会话不删除记忆。
- 最大委派层数默认为 1，范围 0–8；0 禁用子任务委派。它是上限，不是要求模型固定创建这些层。required 任务在最终提交前收集；best-effort 和 detached 的生命周期不同。
- 用户将包含 `SKILL.md` 的技能文件夹放入配置根目录的 `skills/` 并刷新设置列表，技能正文按需读取。
- MCP 通过本地 stdio 或远程 Streamable HTTP 提供工具，有启用／禁用控制及连接独立凭据；不提供 MCP 的资源、提示词、sampling 或 elicitation。
- 网络查询分别配置搜索和网页读取服务、顺序、密钥及首次输出长度。搜索返回来源和摘要，网页读取获取已知 URL 的内容。

## 当前边界

Vista 只监听回环地址，工具使用服务用户的本机权限执行，没有逐次工具审批或文件系统回滚。会话共享真实文件系统，没有固定项目目录，工具要求明确目标路径；文件写工具的乐观校验不覆盖任意 shell 写入。

图片附件目前支持 PNG、JPEG、WebP 和 GIF，每张最多 1 MiB；附件链路不接受音视频，也不展示工具生成的图片。没有内置 LSP、专用 Git 工作流或终端界面。模型／协议资料和本地模拟不能证明每个上游账号、模型均可使用，见[服务商](./providers.zh-CN.md)和[验证](./testing.zh-CN.md)。
