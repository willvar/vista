# 网络配置

[English](./network.md)

## 范围与默认值

「设置 → 网络配置」包含 全局请求及代理配置。
所有 Vista 自有网络客户端默认直连，忽略大小写形式的 `HTTP_PROXY`、`HTTPS_PROXY`、`ALL_PROXY`、`NO_PROXY` 环境变量。
直连仅表示不使用 Vista 应用层代理，操作系统路由、透明网关及隧道仍然有效。
Vista 不删除或注入 shell、外部程序、stdio MCP 服务继承的这些变量；它们的联网及浏览器中的授权页面不受此配置接管。

全局请求用于搜索、网页阅读、模型目录下载、远程 HTTP MCP 及其 OAuth。
各模型连接独立选择直连或 Profile，覆盖推理、模型发现、服务端登录、令牌刷新、标题、压缩和子任务模型请求，不继承 全局请求代理。
内部控制通信保持直连。

## 代理配置

通过「网络配置」标题栏的 + 按钮新增代理配置，在列表中编辑已有配置。
「网络代理」下拉列表只列出已保存的配置；留空或清除选择即不使用代理。
服务连接编辑器只选择已有代理配置，不提供新增入口。
代理选项持续与已保存的网络配置同步，同时保留连接草稿。

Profile 包含稳定 ID、可编辑名称、协议、服务器、端口、认证、可选连接 IP。
HTTP／HTTPS 支持无需认证或 Basic 用户名密码；SOCKS5 支持无需认证或用户名密码的 TCP CONNECT。
HTTPS 代理指 Vista 到代理本身的连接也使用 TLS，不只是 HTTP 代理能够访问 HTTPS 目标。
不提供 UDP、PAC、自动读取系统代理、代理链或原生节点协议。

编辑器仅在 HTTPS 代理下显示「连接 IP」，用于跳过代理服务器域名的 DNS 解析，使用指定 IP 连接。
HTTPS 代理的证书校验默认开启，可在对应配置中关闭。
开关仅控制代理证书，不改变目标 HTTPS 服务的证书校验设置。
TLS SNI 保留代理域名；开启校验时，也按该域名检查证书。
配置以 `insecureSkipVerify: true` 明确表示关闭校验；省略该字段或设为 false 时仍开启校验。
端口默认分别为 HTTP 80、HTTPS 443、SOCKS5 1080；切换协议时，原协议的默认端口随之调整，自定义端口则保留。
回环名称及地址保留 Vista 所在环境的含义，不解释为远端代理的本机。
`localhost` 及以 `.localhost` 结尾的名称依次尝试 IPv6 `::1` 和 IPv4 `127.0.0.1`，某一地址没有监听服务时继续尝试另一地址；不查询外部解析器，也不经过代理。
普通 HTTP 或 SOCKS5 认证本身不提供传输加密。

修改须明确保存。
已保存凭据不回显；入口不变时，两项凭据均留空可保留，选择无需认证则清除。
更换代理入口后复用已有凭据须明确确认。
仍被引用的 Profile 不能删除；提示会列出 全局请求及具体模型连接，并提供跳转入口。
日常列表不显示绑定数量。

模型请求不会自动重试代理认证失败或证书校验失败。
响应前的超时、临时网络故障及明确的套接字连接故障仍遵循模型请求的有界重试策略。

## DNS 与目标地址

直连请求使用系统解析及原生传输的地址回退机制。
通过 HTTP、HTTPS 或 SOCKS5 代理发送的普通请求，将目标域名交给代理解析和连接。
代理入口本身使用系统 DNS，指定「连接 IP」后可避免解析入口域名。
保留原始 URL、HTTP Host、TLS SNI、证书校验域名及业务签名。
Vista 不修改系统 DNS，也不控制外部程序和外部网页阅读服务的 DNS。

本地阅读始终先使用 Vista 所在环境的系统解析器获取并校验目标地址，包括已选代理的情况。
IPv4 和 IPv6 查询并发执行；某个地址族返回空记录或不存在，视为该地址族查询已完成。
若一个地址族查询失败，另一个返回允许访问的地址，Vista 仅使用这些已验证地址自行读取，不将 URL 交给外部阅读器。
仅代理能解析的域名因此无法用于本地阅读，即使普通代理请求能够访问。
实际连接仅使用已验证的地址，并遵循所选出口。
HTTP(S) 代理必须接受连接已验证 IP 和端口的 CONNECT，包括普通 HTTP 目标；拒绝时明确报错，不回退到代理侧域名解析。
目标校验返回多个地址时，通过同一出口错开尝试连接；成功或取消后停止其余尝试，并关闭迟到的连接。

## 网页阅读

适合提交第三方的公网页面继续使用已配置的 Jina／DeepSeek 顺序。
本地、回环及明确的内网 HTTP(S) 页面由 Vista 自行抓取并转换，不将 URL 或正文提交外部阅读器。
对于明确需要读取的内部域名或已授权敏感 URL，`webfetch` 可指定 `reader: "local"`；它决定抓取位置，不表示忽略网络策略。
本地抓取遵循 全局请求代理选择，不执行 JavaScript、不自动登录、不继承浏览器 Cookie，失败后也不回退外部阅读器。
只读取受支持的文本类型；二进制下载继续使用其他工具。
HTML 可转换为 Markdown 或可读文本；超过 DOM 转换内存预算时保留完整 HTML，不截断下载。
转换前按 BOM、HTTP 字符集或文档开头的 HTML meta 声明识别编码；其他文本类型沿用响应头声明的字符集，未声明时默认 UTF-8。

没有可用地址、操作取消或总期限耗尽时，读取失败。DNS 失败本身不会把目标归类为内部目标。
普通域名解析到非公网地址时须明确本地读取意图；禁止目标和不安全重定向仍报错。
本地连接使用已校验的解析结果，重定向逐跳检查。
绑定请求的连接池按规范化域名、已验证 IP 集合及网络策略隔离；集合改变后不会复用到旧地址的连接，同一集合调整地址顺序仍可复用。
绑定连接池最多保留 64 个，淘汰时关闭空闲连接，不中断进行中的请求。
Unicode 和 Punycode 域名写法使用同一规范化绑定标识；非法绑定名称会明确报错。
跨源重定向清除 Referer、Authorization 和 Cookie 请求头；同源重定向保留正常的来源信息。
结果中的敏感 URL 元数据会脱敏，输出沿用完整产物及字节预览机制。
不交给第三方阅读器，不代表工具结果之后不会随对话发给所选模型。

代理配置弹窗提供连接检查，接受 HTTP 和 HTTPS 地址，使用普通请求路径，保留原生 DNS、地址回退、超时及取消行为。检查不会保存或应用设置。

## 状态与 API

`config.json` 的 `network` 分区保存 `globalProxy` 和 `profiles`；Profile 的用户名／密码凭据包位于 `key.json`，归属绑定稳定 ID。
模型锚点只保存 `proxyId`，空选择表示直连。
公开设置和状态只包含凭据存在标记，不包含已解析的私密执行策略。
各次执行及 MCP lease 保留自己的不可变网络快照，保存配置不打断活动流。
HTTP 操作在首次选择全局或服务连接的网络策略时捕获设置，后续选择复用同一快照，包括配置读取失败的结果。
静态资源和本地请求不会仅因经过 HTTP 中间件就读取代理设置或凭据。
搜索 MCP 在延迟初始化和重连时也保留该快照，包括明确选择的直连。
连接池身份包括实际路由及认证，不包含 Profile 显示名称。
MCP HTTP lease 关闭或初始化失败时释放自身拥有的连接池，其他客户端的连接池继续保留。
失败不会静默更换代理、出口或解析器。
应用 HTTP 客户端通过同一构造入口声明使用应用全局或模型连接作用域。
连接客户端必须显式绑定连接策略（包括直连）或私密固定策略，全局请求策略不能代替连接绑定。
自定义、Copilot、Zen 及已配置本地服务的模型发现通过同一入口接收完整连接。
HTTP 包装器显式暴露其网络传输，未声明的包装链会在发送前报错。
对于未传递调用方 context 的 SDK，注入的客户端绑定本次操作的策略、截止时间和取消信号。
运行环境 metadata 凭据代表 Vista 所在执行环境的身份。
AWS EC2 实例角色、ECS／EKS 容器凭据入口（含显式完整 URI 覆盖）、GCE 令牌，以及 Vertex 凭据文件中依赖 metadata 的身份联合，共用身份来源检查。
这些请求要求该连接使用直连；若有效路由会经过代理，请求会在发送前被拒绝，并提示清除代理选择或提供显式凭据。
Vista 不会擅自改变所选路由，也不会接受代理所在环境的运行身份。
拒绝从 metadata 身份来源发出或进入此类来源的重定向，包括同主机重定向。
普通 STS、SSO、OAuth、身份模拟，以及不属于 metadata 的远端令牌来源请求，继续遵循该连接的网络策略。

Bedrock 保留 AWS SDK 的默认凭据链、来源优先级、凭据缓存、入口覆盖、metadata 禁用设置和重试行为。
SDK 自动默认模式中的 metadata 环境发现也受同一检查约束；发现不可用不会妨碍优先级更高的凭据来源工作。
AWS 凭据 HTTP 客户端支持 `AWS_CA_BUNDLE` 和共享配置中的 `ca_bundle`，保留 SDK 的优先级和无效证书包报错。
先通过仅加载传输设置的 SDK 配置读取过程获取 CA／客户端设置，此过程禁用凭据获取和自动环境发现。
正常配置读取保留 CA 解析器要求的 SDK 原生客户端。
凭据请求通过已安装 SDK 的服务构造器取得各服务最终解析的 HTTP 设置，包括默认模式、自动区域判断、连接／TLS 超时预算和服务读取超时。
不同服务／区域的客户端分别拥有连接池；SDK 请求中间件将请求交给 Vista 受身份来源检查和操作生命周期约束的客户端。
冻结后的 SDK 原生客户端未暴露传输底层，因此最小读取适配保留 SDK 导出的空闲读取超时值及超时错误类型。
原生代理钩子会在 SDK 更换拨号器后继续生效；若某条路径遗漏请求接入，会在拨号前拒绝请求。
容器凭据请求显式标记身份来源，因为 SDK 的该分支会单独构造客户端。
凭据解析结束后释放本次操作拥有的空闲连接池。
Vertex 保留 Google 凭据文件优先于 metadata 的顺序，文件解析和令牌交换仍由 `oauth2/google` 完成。
AWS 身份联合配置的区域、角色／凭据及 IMDSv2 URL 均视为身份来源，包括嵌套在身份模拟凭据文件中的配置。
URL 来源的身份联合识别标准 metadata 地址，以及明确的 Google／Azure metadata 请求头；其他远端 URL 来源保留原有路由方式。
没有凭据文件时，Vertex 通过 metadata SDK 获取 GCE 令牌，使用该连接的 HTTP 客户端、本次操作的 context 和五秒总预算。
不会调用 SDK 独立的平台检测或系统 DNS 探针。
SDK metadata HTTP 请求随 Vista 操作取消而停止，包括 SDK 凭据缓存将请求 context 与调用方分离的情况。

- `GET /api/network-config`：返回 `{config, revision, version}`，Profile 已脱敏。
- `PUT /api/network-config`：类型化提交 `{config, revision, reuseCredentials?}`，不得把凭据存在标记或 GET 的脱敏值当成凭据写回。
- `POST /api/network-check`：提交相同草稿及 `profileId`、`target`、当前 `revision`；不保存配置，不发送模型密钥或推理请求。
- 模型连接新增／编辑接受 `proxyId`：编辑时省略保留已有绑定，显式空值选择直连；编辑使用模型设置修订号。
- `PATCH /api/provider-config`：提交 `{key, proxyId, revision}`，只修改网络绑定，保留高级连接字段。

网络配置复用已有 SSE 的作用域化 `network` 主题，推送有界脱敏状态，并保留修订恢复。
并发视图共享 HTTP 补读，关闭视图后仅在没有剩余读取者时取消请求。活跃读取失败时不确认修订号，通过状态流恢复重试。
编辑器保留远端更新时的草稿，拒绝过期保存，重新载入或退出前确认丢弃。
主动检查展示目标、时间、实际出口和失败信息；收到 HTTP 响应只证明网络有响应，不代表业务授权成功。
证书校验失败会区分 HTTPS 代理握手和目标站点的 TLS 握手阶段。
不后台轮询健康状态，不自动访问测试站点。

## 代码入口

- `internal/network/`：配置校验、策略快照、出口选择、地址绑定和传输。
- `internal/network/client.go`、`internal/model/network.go`、`internal/modelcatalog/discovery.go`：作用域客户端、模型执行绑定及连接所属的模型发现。
- `internal/configstore/`：网络凭据拆分及原子发布。
- `internal/server/network_config.go`、`provider_network.go`：类型化设置、检查、引用及绑定修改。
- `internal/tools/webfetch_local.go`：本地目标分类与转换。
- `web/src/NetworkSettings.vue`、`NetworkProfileEditor.vue`、`ProxySelection.vue`：界面及只写草稿。
